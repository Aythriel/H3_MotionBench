Turbo is an experiment using the installed 4-step LoRA at 8 steps, Euler / beta. Compare identity and audio against the base model. Reduced steps can change quality.

Audio is always generated and saved. This distilled workflow has no negative-prompt or CFG control. Model residency changes during generation; the memory reading is a device snapshot.

VRAM budget

Waiting for the live GPU reading.

Component sizes below are weight-file footprints: a planning baseline, not measured VRAM. Each bar compares one component with total GPU capacity.

Components load in stages and can offload to system RAM. Their sum is not a simultaneous VRAM requirement. Activations, attention, dequantization and decode buffers need additional space; larger canvases and longer clips increase that demand. Exact peak VRAM is not estimated here.

Warm-up renders a 256 × 256, 22-frame, 1-step test. It loads the pipeline, creates a video, and does not pin every model in VRAM. Eviction releases all ComfyUI models once idle.

Reference field notes

Start with a clean, single-character, full-body image in the intended pose. Match facing, scale, outfit, equipment, background and padding between endpoints.

Keep the camera locked and ask for one restrained motion. A contact sheet used as a first frame can animate the sheet itself.

Review silhouette, face, hands, equipment, feet and endpoint alignment. Check sound separately. Short drafts test the pipeline; final quality needs a longer native-canvas take.
